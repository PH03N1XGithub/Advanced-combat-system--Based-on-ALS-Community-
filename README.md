# Advanced-combat-system--Based-on-ALS-Community-
It is a c++ Advanced combat system that is a component for ALS(Advanced locomotion system) Community c++ version of ALS


## Leviathan Axe Mechanic

![İsimsiz video ‐ Clipchamp ile yapıldı (3)](https://github.com/user-attachments/assets/2ed7557a-c1b0-43b6-b6a9-67583f8f7fa6)

Throwing & Recall: The axe can be thrown at enemies or objects, and the player can recall it back dynamically, creating a seamless and immersive combat experience.

Interaction with Combat System: The throwing mechanic integrates fluidly with the main combat system, allowing for diverse gameplay strategies.


## Combat System 
![İsimsiz video ‐ Clipchamp ile yapıldı (4)](https://github.com/user-attachments/assets/4f3e1286-9029-45f3-8506-a4f63e7cd052)

Melee Combat: Directional attacks, smooth transitions, and responsive controls, inspired by The Witcher.

Weapon Swapping: Switch between weapons with unique attack patterns and abilities.

Dynamic Feedback: Impactful hit reactions, camera shakes, and particle effects enhance the feel of combat.
